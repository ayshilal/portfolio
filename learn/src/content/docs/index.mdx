## About This Guide

This site documents my learning path through Azure AI development with .NET, covering certifications including **AZ-204**, **AI-102**, **AZ-500**, and **AZ-400 DevOps**.

Each section takes you from concept to implementation in C#, then to deployment and production on Azure — a complete resource from zero to production.
