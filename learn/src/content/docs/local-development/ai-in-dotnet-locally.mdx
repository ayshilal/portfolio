## Overview

Before deploying to Azure, you can build and test AI-powered .NET applications entirely on your local machine. This guide covers setting up your development environment for AI development with .NET.

## Prerequisites

- .NET 8 SDK or later
- Visual Studio 2022 or VS Code with C# Dev Kit
- Docker Desktop (for local model hosting)

## Setting Up the SDK

```csharp
// Install the Azure.AI.OpenAI NuGet package
dotnet add package Azure.AI.OpenAI
dotnet add package Microsoft.Extensions.AI
```
